How to make the application work: use deploy.sh
it runs the script in this order: build.sh -> run.sh
how to use deploy.sh: cd TelemetryApplication chmod +x scripts/deploy.sh chmod +x scripts/build.sh source scripts/deploy.sh
or { source script/build.sh -> ./scripts/run.sh 5002} or (execute command one by one from build.sh and run.sh)

how to run application manually: python ./app.py <port>
python .\app.py 5002

########Setting up docker and containers#######
in windows:
Docker on Windows works a bit differently than on Linux/Mac because Docker needs a Linux kernel to run containers. Docker Desktop + WSL2
powershell
   wsl --install
(Run in PowerShell as Administrator, then restart)
2.	Install Docker Desktop 
o	Download from docker.com
o	During install, make sure "Use WSL 2 instead of Hyper-V" is selected
3.	Verify WSL2 integration 
o	Open Docker Desktop → Settings → Resources → WSL Integration
o	Enable integration with your installed Linux distros (e.g., Ubuntu)
4.	Test it
bash
   docker run hello-world
To open a specific distro:
powershell
wsl -d Ubuntu
cd ~

2. Copy from Windows filesystem into WSL home directory
Windows drives are mounted under /mnt/, e.g. C:\ → /mnt/c/
